# P1 真实场景

P1 是高价值主链路场景：失败不一定阻断发布，但会削弱 v1.2-v1.6 的关键能力可信度。

## 当前 P1 场景

- `reddit-feed-block-or-content-dialogue`：真实动态 feed 或阻塞页读取、滚动、复读并总结。
- `amazon-homepage-state-dialogue`：真实首页可用性/限制状态读取、滚动、复读并总结。
- `mdn-accessibility-long-read-dialogue`：技术文档正文读取、滚动、复读并总结。
- `bbc-news-homepage-dialogue`：新闻首页读取、滚动、复读并总结。
- `anthropic-tools-for-agents-long-read-dialogue`：长文读取、滚动、复读并提炼工具设计建议。
- `cdp-console-network-diagnosis-dialogue`：CDP attach、console、network、performance、detach 全流程。
- `vision-overlay-diagnosis-dialogue`：截图、遮挡检测和 DOM/a11y fallback。
- `shadow-dom-read-dialogue`：发现 open Shadow DOM 并查询内部控件。
- `pdf-manual-read-dialogue`：通过 `bh_doc_read_url` 读取 PDF 页码范围并总结。
- `github-adapter-guidance-dialogue`：检测 GitHub adapter、列出 workflow 并匹配 locator hint。
