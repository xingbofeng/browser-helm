# Roadmap

每个 roadmap 文档都是一个版本级需求说明，并统一使用 11 个模块：

1. 背景
2. 用户故事
3. 目标
4. 不做什么
5. 产品方案
6. 设计图 / 视觉参考
7. 技术方案
8. 目录结构
9. 依赖关系
10. 验收标准
11. 分支建议

任何模块都不能留空。如果不适用，写 `不适用`。

第 8 节「目录结构」必须同时列出本版本涉及的生产代码目录和测试目录：

- `src/`：本版本新增或主要改动的 runtime、tool、UI、storage、schema 等目录。
- `tests/`：按 TDD 推进需要先落位的测试分层，包括 unit、integration、component、e2e、fixtures、helpers 中与本版本相关的部分。
