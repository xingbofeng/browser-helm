# BrowserHelm Context

BrowserHelm is a local-first, a11y-first browser Agent extension. This glossary keeps product and domain language consistent across roadmap, OpenSpec, implementation notes, and code discussion.

## Language

**Agent Kernel**:
The decision loop that turns a user task and current context into the next Agent decision.
_Avoid_: bot core, model loop

**Terminal Decision**:
An Agent decision that ends or pauses a run without invoking a browser or page tool.
_Avoid_: finish tool, fail tool, normal browser tool

**Structured Page Data**:
The v0.3 data contract that organizes page observation outputs into stable page data categories for UI, runtime, trace, and Agent summaries.
_Avoid_: full page parser, form doctor, action executor

**Tab Data**:
A product-facing data category shaped for Cockpit panels and runtime snapshots.
_Avoid_: browser tab, Chrome tab

**Observation Tab Data**:
The Tab Data category for page URL, title, visible text summary, and page state.
_Avoid_: raw DOM

**Ref Tab Data**:
The Tab Data category for stable element references and their summaries.
_Avoid_: selector list

**Interactive Tab Data**:
The Tab Data category for elements that can be clicked, typed into, selected, or otherwise interacted with.
_Avoid_: action readiness

**Form Fields Tab Data**:
The Tab Data category for form fields and their read-only field state.
_Avoid_: autofill, submit action

**Action Readiness**:
The pre-action safety contract that checks whether a future browser action has a valid target and risk state.
_Avoid_: action execution, clicking, typing

**Empty Tab State**:
A Tab Data state meaning the page was checked and no matching data was found.
_Avoid_: unsupported, not implemented

**Unsupported Tab State**:
A Tab Data state meaning the current version or page capability does not support producing that data yet.
_Avoid_: empty, no data

**Deterministic Summary**:
A summary generated by product rules rather than by a model call.
_Avoid_: LLM summary, narrative report

## Relationships

- **Agent Kernel** produces either a tool call or a **Terminal Decision**.
- **Structured Page Data** contains **Observation Tab Data**, **Ref Tab Data**, **Interactive Tab Data**, and **Form Fields Tab Data**.
- **Structured Page Data** is the v0.3 contract layer; complete interactive discovery belongs to v0.31, complete form field reading belongs to v0.32, and **Action Readiness** belongs to v0.33.
- **Tab Data** feeds Cockpit UI and runtime snapshots; Agent context receives only a cropped summary derived from it.
- **Empty Tab State** and **Unsupported Tab State** are distinct; empty means checked-and-none-found, unsupported means not available in the current capability boundary.
- **Deterministic Summary** is the default summary form for **Structured Page Data**.

## Example dialogue

> **Dev:** "Does v0.3 implement full form diagnosis?"
> **Domain expert:** "No. v0.3 defines **Structured Page Data** and **Tab Data** boundaries. Full form reading is v0.32."

> **Dev:** "The forms tab has no fields. Is that empty?"
> **Domain expert:** "Only if the page was checked and no forms were found. If v0.3 has not implemented full form reading, that is **Unsupported Tab State**."

## Flagged ambiguities

- "tab data" can sound like a Chrome browser tab. Resolved: **Tab Data** means a Cockpit/product data category, not a browser tab.
- "0.3" was used to mean both the whole v0.3 family and the specific Structured Page Data version. Resolved: **Structured Page Data** is v0.3; v0.31/v0.32/v0.33 remain separate follow-up versions.
- "empty" was used for both no data and not implemented. Resolved: **Empty Tab State** means checked-and-none-found; **Unsupported Tab State** means unavailable in the current version or page capability.
